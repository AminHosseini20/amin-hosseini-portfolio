# Amin Hosseini — Portfolio

A responsive one-page personal portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Personalize it

In `js/script.js`, replace the values in `CONFIG` with real URLs or local asset paths for the logo, avatar, photo, and video. The supplied logo and photos are in `assets/images/`; the video panel uses the supplied team image as its poster until a video is added.

The provided GitHub, Telegram, WhatsApp, and email links are already wired in.

## Preview locally

Run `python -m http.server 4173` from this folder and open `http://localhost:4173`.
